Keyframe Awards

 Keyframe Awards is an independent digital awards platform created to celebrate excellence across music, movies, television, internet culture, and creative content.

Website: https://keyframe-awards.com

 Keyframe Awards was built as a fan-driven awards platform that allows users to nominate and vote for their favorite creators, artists, movies, music videos, and internet moments. 

 The platform focuses on community participation and recognizing both mainstream and internet culture achievements.

Features
- Nomination system for multiple award categories

- Voting system with daily vote limits to reduce abuse

-Responsive and modern user interface

-Automated email notifications for users

-Dedicated pages for categories, rules, about, and contact

-Clean and professional design optimized for desktop and mobile

Categories Covered:
Music
Movies & TV
Gaming
Internet Culture / Memes
Content Creators
Sports (select categories)

Tech Stack
Frontend: HTML, CSS, JavaScript
Hosting: GitHub Pages / Custom Domain / Firebase Authentication
Email Automation: Resend + Cloudflare Workers
Domain & DNS: Cloudflare

Project Purpose
The goal of Keyframe Awards is to create a fun, community-driven awards experience that highlights both popular and emerging talent across entertainment and internet culture.
